# Branches, commits, and recording decisions

## Git

- Branches: `feat/<slug>` or `fix/<slug>`.
- Commit subjects: short, imperative (e.g. "Add AGENTS.md with repo
  conventions").

## Recording decisions and scope

- New design decisions get a numbered entry appended to `docs/decisions.md`.
- Milestone or scope changes go in `docs/roadmap.md`.
